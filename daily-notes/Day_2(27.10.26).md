# День второй

Тут уже стоит записать кое-что из теории. А именно - типы данных.
Если кратко:

int - целое

double - дробное

bool - логическое (True/False)

string - строка

массивы записываются как int[], string[] и тд. С каждым измерением просто добавляется [] в конце

Методы записываются по шаблону:

static [тип данных которые мы возвращаем] [имя метода]([принимаемые данные])
{
    [тело метода];
    return [возвращаемые данные];
}

В целом потихоньку, полегоньку набираем обороты. Не торопимся, но и на месте не стоим. Посмотрим, что будет завтра.
