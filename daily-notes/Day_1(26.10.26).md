# День 1: конспект

## Git

**Цепочка:** файл → `git add` (индекс) → `git commit` (локальная история) → `git push` (GitHub). Если непонятно, где ты, смотри `git status`.

| Команда | Что делает |
|---|---|
| `git config --global user.name / user.email` | подпись коммитов (`--global`: для всех репозиториев) |
| `git config --global init.defaultBranch main` | имя первой ветки |
| `git init` | превращает папку в репозиторий (создаёт `.git`) |
| `git add <файл>` / `git add .` | добавляет изменения в индекс |
| `git commit -m "текст"` | фиксирует индекс как коммит (`-a`: брать изменённые отслеживаемые файлы, `--amend`: переделать последний коммит) |
| `git status` | что изменено, что в индексе, что не отслеживается |
| `git log --oneline` | история, по строке на коммит (`--graph`, `-n 5`, `--stat`) |
| `git branch -M main` | переименовать текущую ветку в `main` |
| `git remote add origin <URL>` | привязать удалённый репозиторий (`git remote -v`: список) |
| `git push -u origin main` | отправить ветку и запомнить связку (`-u`), дальше хватит `git push` |

Сообщения коммитов: глагол в повелительном наклонении (`Add`, `Fix`, `Remove`), один коммит = одно логическое изменение.

## .gitignore

- `dotnet new gitignore` создаёт готовый шаблон для .NET (`bin/`, `obj/`, файлы IDE и т. д.).
- `.gitignore` действует только на файлы, **за которыми Git ещё не следит**.
- Уже отслеживаемые файлы снимаются так: `git rm -r --cached <пути>`:
  - `-r`: рекурсивно (для папок),
  - `--cached`: убрать только из индекса, файлы на диске остаются,
  - `-n`: пробный запуск без изменений.
- Эти два инструмента независимы: команда `git rm --cached` не меняет содержимое `.gitignore`.
- Секреты (токены, строки подключения) в `.gitignore` добавляются вручную.

## Исправление старого коммита (rebase)

1. Убедиться, что рабочее дерево чистое, сборочных папок нет (`rmdir /s /q FirstSteps\bin FirstSteps\obj`).
2. `git rebase -i HEAD~N`: N на единицу больше, чем число коммитов в списке (`HEAD~N` берёт последние N, а базой становится следующий за ними).
3. В списке заменить `pick` на `reword` у нужного коммита. Подпись после `#` на сообщение не влияет.
4. Во втором редакторе исправить само сообщение.
5. `git log --oneline`, затем `git push --force-with-lease` (перезапись истории, но с защитой).
6. В любой момент: `git rebase --abort` возвращает всё как было.

Правило: переписывать историю безопасно, только пока репозиторий ничей, кроме твоего.

## Vim (редактор Git по умолчанию)

- **Команды работают только на латинской раскладке.**
- `i`: режим вставки; `Esc`: выход из него; `cc`: очистить строку и вставлять; `:wq` + Enter: сохранить и выйти; `ggdG`: удалить всё.

## Командная строка (Windows)

- `cd ..`: на уровень вверх; `cd ..\..`: на два; `cd /d D:\папка`: другой диск.
- `rmdir /s /q <папка>`: удалить папку с содержимым без подтверждения.
- Пути: в Git лучше прямые слэши `/` (работают везде); `.\FirstSteps\bin` из Tab-дополнения тоже понятен Git в cmd и PowerShell.
- `&&`: выполнить следующую команду, только если предыдущая успешна.

## C# и .NET

- `dotnet --version`, `dotnet new console -o <папка>`, `dotnet run`.
- Операторы верхнего уровня: код пишется прямо в `Program.cs`, без `class` и `Main`.
- Ввод: `Console.ReadLine()` возвращает `string?` (может быть `null`).
- Преобразование: `int.TryParse(input, out int n)` возвращает `true`/`false`, а число кладёт в `n`. Безопаснее `int.Parse`, который падает на мусоре.
- Цикл: `for (int i = 1; i <= n; i++)`.
- `%`: остаток от деления; `==`: сравнение (один `=` это присваивание); `&&`: «и»; `!`: «не».
- Ветки `if / else if / else` проверяются сверху вниз, срабатывает первая подошедшая: частное условие («делится на 3 и на 5») ставят первым.
- Ранний выход: если ввод некорректен, `return` сразу, а не пустой блок `if`.
- Отладочные `Console.WriteLine(...)` убирать из готовой программы.

## Python (разбор знаний)

- `b = a` для списка: второе имя на тот же объект, поэтому `b.append(4)` меняет и `a`.
- `a.copy()`: поверхностная копия, вложенные списки остаются общими; `copy.deepcopy(a)`: полная копия.
- Значение по умолчанию `acc=[]` вычисляется один раз при определении функции: все вызовы делят один список. Решение: `acc=None` и `if acc is None: acc = []`.
- Мелкая привычка: перепроверять себя, читая код внимательно (в первом вопросе ошибка была из-за невнимательности, а не незнания).
